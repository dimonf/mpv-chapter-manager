the plugin main menu:
  * 1. set start time
  * 2. set end time
  * w. duplicate last a-b point
  * s. save positions to file
  * r. read positions from file
  * l. loop toggle
  * p. show loop entries (enters loop-entries mode)
  * -/+ change OSD font size
  * ESC hide

loop-entries mode menu:
  * x. delete entry by index
  * m. toggle "selected" by index
  * r. rename entry by index
